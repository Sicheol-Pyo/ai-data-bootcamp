## 🗓️ 학습 기록

날짜별(`D001` ~ `D052`) 폴더에 학습 노트북과 보고서(`.md`)를 정리했습니다.

| 구간 | 주제 | 폴더 |
|:---:|---|:---:|
| 🛠️ **환경 · Python** | Github 설정 · Python 복습 · 데이터 분석 라이브러리 입문 | D001 ~ D002 |
| 🐼 **데이터 처리** | pandas 인덱싱 · 결측치 · 병합 · 피벗 · 그룹 연산 · 문자열 · 날짜 · `apply` · 대용량(청크 · Polars) | D003 ~ D007 |
| 📊 **시각화 · 수집** | Plotly · 데이터 랭글링 종합 · `requests` · BeautifulSoup · Selenium · 윤리적 크롤링 | D008 ~ D011 |
| 📐 **통계 기초** | 통계분석의 기초 · 추론통계 · 신뢰구간 · 가설검정 · 상관과 회귀 · 인과 · A/B 테스트 | D012 ~ D017 |
| 🤖 **머신러닝** | 선형 · 로지스틱 회귀 · 의사결정나무 · 앙상블 · 과적합 · 교차 검증 · 분류 지표 · 불균형 · 피처 선택 · 데이터 누수 · 군집화 · 차원축소 · SHAP | D018 ~ D024 |
| 🗄️ **SQL** | SQL 실습 · SQL 리포트 | D025 ~ D031 |
| 🎛️ **분석 · 대시보드** | 바이브하게 분석하기 · 대시보드 시각화 | D032 ~ D033 |
| 🎲 **통계 모델링** | MLE · 베이즈 추정 · GLM · 포아송 회귀 · 부트스트랩 · 계층 모형 · MCMC | D034 ~ D038 |
| ⏳ **시계열** | 분해 · 정상성 · ARIMA · SARIMA · 예측 평가 · Prophet · 글로벌 모델 · Chronos-2 · 공변량 · 분위수 예측 | D039 ~ D048 |
| 📝 **비정형 데이터 (자연어 처리)** | 형태소 토큰과 문서 비율 · TF-IDF · 집단 특징 단어 · 문장 임베딩 · 의미 검색 · BERTopic 토픽 모델링 | D049 ~ D052 |
