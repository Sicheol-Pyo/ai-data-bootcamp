# 통계적 검정과 인과추론 종합 과제
## 사용한 데이터셋 : cookie_cats
## 질문과 가설 정하기 :
- 귀무가설: gate_30과 gate_40의 유저 플레이 타임은 차이가 없다.
- 대립가설: gate_40인 경우가 gate_30 보다 유저가 더 오래 플레이한다. (단측 검정)

## 검정  고르기
- 해당 데이터는 정규성 위반, 등분산성 만족으로 Mann-Whitney U 검정으로 진행하였습니다.

## 검정 수행하고 3종 세트로 보고
1. 점추정 (차이): -1.00  (gate_40 중앙값 - gate_30 중앙값)
2. 95% 신뢰구간: (-1.00, 0.00)
3. 효과 크기: 0.0075  (rank-biserial correlation r)

점추정(중앙값 차이 -1.00), 95% 신뢰구간(-1.00~0.00, 부트스트랩으로 계산), 효과크기(rank-biserial r=0.0075) 모두, "gate_40이 gate_30보다 통계적으로도, 실질적으로도 의미 있게 더 오래 플레이하지 않는다"는 같은 결론을 뒷받침합니다. 특히 신뢰구간이 0을 포함하고 효과크기가 거의 0이라는 것은, 오늘 Mann-Whitney 검정에서 확인한 "유의하지 않다"는 결과를 수치로 한 번 더 확인시켜 주는 것입니다.

### 5. 의사결정: 보류 (Hold)
- 근거: gate_40이 gate_30보다 유저들이 더 오래 플레이한다는 통계적 근거가 없으며, 오히려 중앙값·평균 모두 gate_30이 근소하게 높음. gate를 40으로 변경할 이유가 없으므로, 현재 상태(gate_30) 유지를 권장. 만약 gate_40 도입을 계속 검토하려면, MDE 이하의 차이까지 탐지 가능한 표본(그룹당 약 38,899명 이상은 이미 충족되었으나, 더 작은 효과를 보려면 훨씬 더 많은 표본 필요)을 추가 확보해야 함.

### 6. 한계
- 이 결론은 "정규성 위반 시 Mann-Whitney가 적절하다"는 가정, "부트스트랩 신뢰구간이 실제 표집분포를 잘 근사한다"는 가정에 기대고 있음
- sum_gamerounds의 극단적 이상치를 제거하기 전/후로 결론이 달라지는지는 별도로 검증하지 않았음 (B안 미실시)
- 이 데이터만으로는 "왜" gate_40이 더 낫지 않은지(예: 유저가 초반에 이탈해서 gate_40에 도달조차 못 하는 것인지)는 알 수 없음 — 퍼널(funnel) 분석 등 추가 데이터가 필요함
- 리텐션(retention_1) 기준의 MDE 계산은 sum_gamerounds와는 별개의 지표이므로, 두 지표를 종합한 최종 결론이 아니라 참고 정보로 취급해야 함
