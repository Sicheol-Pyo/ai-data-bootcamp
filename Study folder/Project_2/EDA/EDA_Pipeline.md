## 실행 방식
"EDA_Pipeline 실행해줘" 요청 시 아래 3단계로 진행하며, 각 단계 종료 시 사용자 확인/입력을 받은 후에만 다음 단계로 진행한다.

## 1단계: 개요 및 진단 (요청 즉시 실행 → 정지)
- `eda_diagnostics.py <입력 CSV 경로>` 를 실행한다
- 출력된 내용을 그대로 리포트의 "1. 데이터 개요" ~ "2. 진단 결과"에 옮겨 적는다 (재계산·재작성·요약·생략 금지)
- 특이사항(2-4)만 스크립트 출력을 참고하여 실제로 서술한다
- 여기까지 작성 후 정지 → 사용자의 처리 방향 의견 대기
## 2단계: 처리 결정 반영 + 후보 통계 제시 (사용자 의견 수신 후 실행 → 정지)
## 3단계: 최종 리포트 완성 (사용자 선택 수신 후 실행)
- 선택된 항목만 5-1, 5-2...로 반영 (미선택 항목은 제외)
- 6. 후속 권고: 남은 한계 + 대시보드 후보 지표/질문 후보 포함

## 파일 경로 규칙
- 입력 데이터: Dataset 폴더 내 지정된 파일 사용 (요청 시 파일명 명시)
- 파일명: portfolio.json, profile.json, transcript.json
- 출력 리포트: EDA 폴더에 {Dataset 파일명}_EDA_Report.md로 저장
- 각 단계 종료(정지) 시점마다, 그때까지 작성된 내용을 위 출력 리포트 파일에 저장/업데이트하고, 채팅에는 "N단계 완료, 파일 확인 후 의견 전달 바람" 정도로만 안내한다
- 사용자는 저장된 md 파일을 직접 열어 확인한 후, 다음 단계 진행에 필요한 의견을 채팅으로 전달한다

## 주의사항
- 문구는 ~함 ~필요 ~확인 등과 같이 개조식 문체 사용
- 컬럼명은 어떤 섹션에서든 원본 그대로 표기(번역·의역·요약 금지), 필요시 괄호로 한글 설명만 추가
- 표로 지정된 항목은 반드시 마크다운 표 문법으로 출력, 요약 문장·범위 표현으로 대체 금지, 지정된 모든 행을 생략 없이 포함
- 지정된 템플릿 구조 외 항목(작성일자, 작성시간, 부제, 요약 문구 등) 임의 추가 금지 — 오직 명시된 섹션과 표 구성만 출력

## 스크립트 기반 진단 규칙 (재현성 확보)
- 결측/이상치/중복 계산은 절대 자연어로 새로 판단하지 말고, 반드시 `eda_diagnostics.py <CSV파일경로>` 를 실행한 결과만 사용한다
- 스크립트가 출력한 표를 그대로 리포트에 옮겨 적는다 (재계산·재작성·재해석 금지, 숫자 임의 수정 금지)
- 스크립트 상단의 `NATURAL_KEY_COLUMNS`(자연키 컬럼 조합)와 `OUTLIER_EXCLUDE_COLUMNS`(이상치 분석 제외 컬럼)는 데이터셋이 바뀔 때마다 사용자가 직접 확인/수정한다
