# Tableau Public으로 "전세계 결핵 부담 추이" 대시보드 만들기

> 이 가이드는 우리가 함께 확정한 디자인 스펙(`TB_Burden 대시보드 디자인_20260907.xlsx`)을 **Tableau Public(무료)** 화면에서 그대로 따라 만들 수 있도록 클릭 단위로 정리한 것입니다.
> Tableau를 한 번도 써본 적이 없어도 순서대로 따라오면 완성되도록 구성했어요. 필수 단계와 "심화(선택)" 단계를 구분해두었으니, 처음엔 필수 단계만 완료해도 충분히 완성도 있는 대시보드가 됩니다.

**같이 받은 파일**: `TB_Burden_BI용_데이터.csv` (5,120행 — 이 가이드 전체에서 사용할 데이터)

## 0. 준비하기

1. **Tableau Public Desktop 설치** — `tableau.com/products/public` 에서 무료 다운로드 후 설치합니다. (로그인은 무료 계정으로 가능하며, 완성된 통합문서는 Tableau Public 서버에 게시하는 방식으로 저장됩니다. 이 데이터는 WHO 공개 데이터라 게시해도 문제 없습니다.)
2. 설치 후 실행하면 왼쪽에 **"연결"** 패널이 보입니다. **텍스트 파일(Text file)** 을 클릭하고 `TB_Burden_BI용_데이터.csv` 를 선택하세요.
3. 데이터가 미리보기 되면 화면 아래 시트 탭 중 **"Sheet 1"** 로 이동해 새 화면을 시작합니다.

**필드 확인** — 왼쪽 "데이터" 창에 아래 필드들이 보여야 합니다 (안 보이면 자동 인식 오류이니 데이터 소스 화면에서 데이터 타입을 확인하세요):

| 필드명 | 의미 | 타입 |
|---|---|---|
| Country | 국가명 | 텍스트(차원) |
| ISO3 | 국가 3자리 코드 | 텍스트(차원) |
| Region_Code / Region_Name | WHO 지역 코드/이름 (AFR·AMR·EMR·EUR·SEA·WPR) | 텍스트(차원) |
| Year | 연도(1990–2013) | 정수(차원) |
| Population | 추정 총 인구수 | 숫자(측정값) |
| Incidence_Cases / Incidence_Rate_per100k | 발생자 수 / 발생률(10만 명당) | 숫자 |
| Prevalence_Cases / Prevalence_Rate_per100k | 유병자 수 / 유병률 | 숫자 |
| Mortality_Cases / Mortality_Rate_per100k | 사망자 수(HIV 제외) / 사망률 | 숫자 |
| Mortality_HIV_Cases / Mortality_HIV_Rate_per100k | HIV 양성 사망자 수 / 사망률 | 숫자 |
| Incidence_HIV_Cases / Incidence_HIV_Rate_per100k | HIV 양성 발생자 수 / 발생률 | 숫자 |
| Case_Detection_Rate_pct | 사례 발견율(%) | 숫자 |

> Tableau는 기본적으로 텍스트 필드를 "차원(Dimension)", 숫자 필드를 "측정값(Measure)"으로 자동 분류합니다. **Year**만 예외로, 왼쪽 창에서 Year를 우클릭 → "차원으로 변환"이 이미 되어 있는지 확인하세요(연속 축이 아니라 낱개 연도로 다뤄야 슬라이더/막대가 깔끔합니다).

## 1. 지표 선택 매개 변수 만들기 (필수 컨트롤)

디자인 스펙의 "①공통 컨트롤 – 지표 선택"에 해당합니다. 트렌드 차트와 지도 색상이 이 매개 변수 하나로 함께 바뀝니다.

1. 왼쪽 데이터 창 오른쪽 위 드롭다운(▾) → **매개 변수 만들기**
2. 이름: `지표 선택`
3. 데이터 유형: 문자열
4. 허용 가능한 값: **목록**, 아래 5개를 순서대로 추가
   - 발생률 (Incidence)
   - 유병률 (Prevalence)
   - 사망률-HIV제외 (Mortality)
   - 사망률-HIV양성 (Mortality HIV+)
   - HIV양성 발생률 (Incidence HIV+)
5. 확인 → 왼쪽 데이터 창 맨 아래 "매개 변수" 목록에 생성된 걸 확인하고, **우클릭 → "매개 변수 표시"** 로 화면에 드롭다운 컨트롤을 띄웁니다.

이제 이 매개 변수 값에 따라 절대값/비율 값을 골라주는 계산된 필드 2개를 만듭니다.

**계산된 필드 ①: `선택지표_절대값`**
```
CASE [지표 선택]
WHEN '발생률 (Incidence)' THEN SUM([Incidence_Cases])
WHEN '유병률 (Prevalence)' THEN SUM([Prevalence_Cases])
WHEN '사망률-HIV제외 (Mortality)' THEN SUM([Mortality_Cases])
WHEN '사망률-HIV양성 (Mortality HIV+)' THEN SUM([Mortality_HIV_Cases])
WHEN 'HIV양성 발생률 (Incidence HIV+)' THEN SUM([Incidence_HIV_Cases])
END
```

**계산된 필드 ②: `선택지표_비율(10만명당)`** — 인구 가중 평균(국가별 단순평균이 아니라, "건수 합계 ÷ 인구 합계"로 계산해야 여러 나라를 묶었을 때 통계적으로 올바릅니다)
```
CASE [지표 선택]
WHEN '발생률 (Incidence)' THEN SUM([Incidence_Cases]) / SUM([Population]) * 100000
WHEN '유병률 (Prevalence)' THEN SUM([Prevalence_Cases]) / SUM([Population]) * 100000
WHEN '사망률-HIV제외 (Mortality)' THEN SUM([Mortality_Cases]) / SUM([Population]) * 100000
WHEN '사망률-HIV양성 (Mortality HIV+)' THEN SUM([Mortality_HIV_Cases]) / SUM([Population]) * 100000
WHEN 'HIV양성 발생률 (Incidence HIV+)' THEN SUM([Incidence_HIV_Cases]) / SUM([Population]) * 100000
END
```

> 두 필드 모두 "만들기" 방식: 데이터 창 상단 드롭다운 → **계산된 필드 만들기** → 이름 입력 후 위 수식 붙여넣기.

## 2. 맨 위 — 전세계 추이 차트 (혼합형 막대+꺾은선)

세계 전체(연도별) 흐름을 보여주는 차트로, **Year 필터의 영향을 받지 않고 1990~2013 전체를 항상 보여줍니다.**

1. 새 워크시트를 만들고 이름을 `01_전세계추이` 로 변경
2. **Year**를 열(Columns) 선반으로 드래그 (자동으로 "연도(Year)"라는 이산형 초록 필드가 됩니다 — 초록색인지 확인)
3. **`선택지표_절대값`** 을 행(Rows) 선반으로 드래그 → 마크 유형을 "막대"로 지정
4. **`선택지표_비율(10만명당)`** 을 다시 행(Rows) 선반에 (같은 행에, `선택지표_절대값` 오른쪽에) 드래그 → 두 번째 축이 추가됩니다
5. 두 번째 축(오른쪽 y축) 위에서 **우클릭 → "이중 축"** 선택 → 두 개의 y축이 겹쳐진 하나의 차트가 됩니다
6. 두 번째 축(비율)의 마크 카드에서 마크 유형을 "선"으로 변경
7. 우클릭으로 오른쪽 축 위에서 **"축 동기화"는 체크하지 마세요** — 절대값(수천~수만 단위)과 비율(0~수백 단위)은 스케일이 다르므로 각자 다른 눈금을 가져야 합니다
8. 축 제목 수정: 왼쪽 y축 더블클릭 → "추정 건수(명)", 오른쪽 y축 → "인구 10만 명당 비율", x축 → "연도"
9. 시트 제목을 동적으로: 제목 더블클릭 → `<지표 선택> 전세계 추이 (1990–2013)` 처럼 매개 변수 삽입(삽입 버튼에서 "지표 선택" 선택)

## 3. 국가 / 지역 / 전세계 스코프 선택 컨트롤

디자인 스펙의 "국가·Region·전세계 토글"에 해당하며, **지도만** 이 선택에 반응해서 강조됩니다.

1. 매개 변수 만들기: 이름 `보기 단위`, 문자열, 목록 값: `전세계`, `지역`, `국가`
2. 매개 변수 만들기: 이름 `지역 선택`, 문자열, 목록 값: `AFR`, `AMR`, `EMR`, `EUR`, `SEA`, `WPR` (6개 WHO 지역 코드)
3. 매개 변수 만들기: 이름 `국가 선택`, 문자열, **허용 가능한 값을 "필드에서"** 로 지정하고 필드는 `Country` 선택 → 219개국이 자동으로 드롭다운 목록에 채워집니다(직접 하나하나 입력할 필요 없음)
4. 세 매개 변수 모두 우클릭 → "매개 변수 표시"로 화면에 띄웁니다. `보기 단위`가 "지역"일 때만 `지역 선택`이, "국가"일 때만 `국가 선택`이 의미를 가지므로, 대시보드에서 두 컨트롤을 나란히 두면 됩니다(자동으로 숨겨지진 않지만 사용자가 헷갈리지 않도록 안내 문구를 옆에 붙이는 걸 추천)

## 4. 세계지도 차트

디자인 스펙 "③세계지도 차트"에 해당하는 핵심 화면입니다.

1. 새 워크시트 `02_세계지도`
2. **Country** 필드를 더블클릭(또는 행/열 선반 밖으로 드래그) — Tableau가 국가명을 자동으로 지리적 역할(위도/경도)로 인식하면 지도가 바로 나타납니다
   - ⚠️ 자동 인식이 안 되는 국가가 있으면 지도 오른쪽 위에 회색 삼각형 경고가 뜹니다. 클릭 → "위치 편집(Edit Locations)"에서 목록의 국가를 드롭다운으로 하나씩 맞는 나라에 매칭해주세요(WHO 데이터의 공식 국가명 중 일부, 예: "Democratic People's Republic of Korea" 같은 표기가 Tableau 지도 DB와 다를 수 있습니다)
3. 마크 유형을 **"채워진 맵(Filled Map)"** 으로 변경(마크 카드 상단 드롭다운)
4. **`선택지표_비율(10만명당)`** 을 **색상(Color)** 선반으로 드래그
5. **Year**를 **필터** 선반으로 드래그 → 아래 6단계의 "연도 슬라이더"용 계산된 필드로 교체할 예정이니 일단 넘어가도 됩니다 (6단계 참고)

### 4-1. 순차형(sequential) 색상 + 이상치 완화

발생/유병/사망 등은 "많고 적음"의 한 방향 크기(magnitude) 데이터이므로 **빨강-초록 두 색(diverging)이 아니라, 연한 주황 → 진한 빨강의 한 방향(sequential) 색**을 씁니다. 색맹 사용자도 구분 가능하고, "중간값 기준 좋음/나쁨"이라는 잘못된 인상을 주지 않습니다.

1. 색상 범례 우클릭(또는 색상 선반 클릭) → **"색상 편집"**
2. 팔레트: 아무 순차형(Sequential) 팔레트 선택 후 **"고급"** 펼치기
3. **시작 색**: 연한 주황(예: `#FFF3D6`), **끝 색**: 진한 빨강(예: `#B3121A`) — 팔레트 하단에 "사용자 지정 순차형"이 있으면 직접 두 색을 지정할 수 있습니다
4. **"전체 범위" 대신 "고급 → 시작/끝 값"** 을 직접 입력해 상위 5%(p95) 근처에서 색이 포화되도록 캡을 씌웁니다(왜도가 큰 데이터라 극단값 1~2개 때문에 대부분 국가가 밋밋한 색으로 뭉개지는 걸 방지):

   | 지표 | 색상 끝(End) 값으로 입력 |
   |---|---|
   | 발생률 | 약 500 |
   | 유병률 | 약 715 |
   | 사망률(HIV 제외) | 약 87 |
   | 사망률(HIV 양성) | 약 57 |
   | HIV양성 발생률 | 약 253 |

   > 5개 지표가 매개 변수 하나로 전환되므로, 색상 끝 값도 지표가 바뀔 때마다 다시 설정해줘야 합니다(Tableau는 지표별로 다른 캡 값을 자동 전환해주진 않습니다 — 이 부분이 Tableau의 한계이며, 하나의 고정값으로 타협하거나 아래 "심화" 방법으로 해결할 수 있습니다).

   **심화(선택)**: 지표별로 다른 캡 값을 자동 적용하려면, `선택지표_비율(10만명당)` 을 그대로 쓰는 대신 `MIN([선택지표_비율(10만명당)], 지표별_캡값)` 형태의 계산된 필드를 하나 더 만들어 색상 선반에 올리면 국가 하나하나가 이미 캡핑된 값을 갖게 되어 색상 범위를 고정값 하나로만 설정해도 됩니다. `지표별_캡값`은 위 표를 그대로 CASE 문으로 넣으면 됩니다.

5. **결측치 처리**: Case_Detection_Rate_pct처럼 결측이 있는 지표를 고를 경우, 데이터 없는 국가는 Tableau가 자동으로 회색 "Null" 마크로 표시합니다(디자인 스펙의 "데이터 없음 = 회색" 요건과 일치) — 별도 설정 불필요.

### 4-2. 선택한 국가/지역 강조 (심화, 선택 단계)

디자인 스펙: "선택 시 지도만 테두리로 강조, 채우기 색은 그대로 유지"

1. 계산된 필드 `강조_대상여부`:
```
IF [보기 단위] = '국가' AND [Country] = [국가 선택] THEN 1
ELSEIF [보기 단위] = '지역' AND [Region_Name] = [지역 선택] THEN 1
ELSE 0
END
```
2. 지도 워크시트에서 **"맵 레이어 추가"**(지도 위 마우스오버 시 왼쪽에 뜨는 레이어 아이콘, 또는 메뉴 지도 → 배경 레이어)를 눌러 같은 Country 필드로 **두 번째 채워진 맵 레이어**를 추가
3. 새 레이어의 필터에 `강조_대상여부` = 1 만 통과하도록 설정
4. 새 레이어의 채우기 색을 **"없음/투명"** 으로, 테두리(윤곽선)만 굵고 진하게(예: 남색 `#1A3A6B`, 두께 최대)로 설정
→ 결과적으로 원래 지도의 데이터 색은 그대로 보이면서, 선택된 국가/지역 위에만 굵은 테두리가 덧씌워집니다.

> 이 단계가 어렵게 느껴지면 건너뛰어도 대시보드 자체는 정상 작동합니다 — 강조 표시만 빠지는 것뿐입니다.

## 5. 연도 슬라이더 (지도 + 스냅샷 패널 공용)

1. `Year` 필드를 워크시트 `02_세계지도`의 **필터** 선반으로 드래그 → "단일 값(슬라이더)" 선택 → 확인
2. 필터 우클릭 → **"필터 표시"** → 슬라이더 컨트롤이 화면에 나타납니다
3. 이 필터를 대시보드에서 다른 시트(스냅샷 패널)와 공유하려면: 대시보드 화면에서 슬라이더 우클릭 → **"적용 대상 워크시트" → "이 데이터 원본을 사용하는 모든 항목"** 선택 (7단계 스냅샷 시트들과 자동 연동됩니다)

> 주의: 맨 위 "01_전세계추이" 차트는 이 Year 필터의 영향을 받으면 안 됩니다(항상 1990~2013 전체를 보여줘야 함). 3번 옵션 대신 "선택한 워크시트"를 눌러 `02_세계지도`와 7단계에서 만들 스냅샷 시트들만 체크하고 `01_전세계추이`는 체크 해제하세요.

## 6. 세부 지표 스냅샷 패널 (8개 지표 + 전년대비 증감)

디자인 스펙 "⑤세부 지표 스냅샷 패널"입니다. 전년대비 값도 함께 보여줘야 하므로, **Year 필터를 걸지 않고** 계산된 필드 안에서 "선택한 연도"와 "그 전 연도"를 직접 비교합니다(이렇게 하면 전년도 데이터가 필터로 잘려나가지 않습니다).

먼저 매개 변수가 하나 더 필요합니다(5단계 슬라이더와는 별도로, 계산식에서 참조할 정수형):
- 매개 변수 만들기: 이름 `기준연도`, 정수, 범위 1990~2013, 1씩 증가 → "매개 변수 표시"로 띄우고, 이 슬라이더 하나만 화면에 두고 5단계의 Year 필터 슬라이더는 대시보드에서 숨겨도 됩니다(둘이 중복이므로 `기준연도` 매개 변수 하나로 통일하는 걸 추천).

8개 지표 각각에 대해 아래 3개의 계산된 필드를 만듭니다 (예시는 "① 추정 총 인구수" 기준, 나머지 7개도 필드명만 바꿔 동일하게 반복):

**`인구_당해연도`**
```
SUM(IF [Year] = [기준연도] THEN [Population] END)
```
**`인구_전년도`**
```
SUM(IF [Year] = [기준연도] - 1 THEN [Population] END)
```
**`인구_증감률`**
```
([인구_당해연도] - [인구_전년도]) / ABS([인구_전년도])
```

8개 지표와 집계 방식(디자인 스펙에서 확정한 통계적으로 올바른 집계 기준):

| # | 지표(한글) | 원본 필드 | 집계 방식 | 증감 해석 |
|---|---|---|---|---|
| 1 | 추정 총 인구수 | Population | 단순 합계 | 중립(색 없음) |
| 2 | 추정 결핵 유병자 수 | Prevalence_Cases | 단순 합계 | 증가=나쁨(빨강) |
| 3 | 추정 결핵 사망자 수(HIV 제외) | Mortality_Cases | 단순 합계 | 증가=나쁨 |
| 4 | 추정 HIV 양성 결핵 사망자 수 | Mortality_HIV_Cases | 단순 합계 | 증가=나쁨 |
| 5 | 추정 결핵 신규 발생자 수 | Incidence_Cases | 단순 합계 | 증가=나쁨 |
| 6 | 신규 발생자 중 HIV 비율(%) | = HIV발생÷전체발생×100 | **비율 계산**(합계÷합계) | 증가=나쁨 |
| 7 | 추정 HIV 양성 신규 발생자 수 | Incidence_HIV_Cases | 단순 합계 | 증가=나쁨 |
| 8 | 사례 발견율(%) | = Σ(발생×발견율)÷Σ발생×100 | **가중 비율**(아래 참고) | **증가=좋음(초록, 유일한 예외)** |

지표 6 (신규 발생자 중 HIV 비율)은 단순 합계가 아니라 비율이므로:
```
HIV비율_당해연도 = SUM(IF [Year]=[기준연도] THEN [Incidence_HIV_Cases] END) 
                    / SUM(IF [Year]=[기준연도] THEN [Incidence_Cases] END) * 100
```
(전년도 버전도 `[기준연도]-1`로 동일하게 하나 더 생성)

지표 8 (사례 발견율)은 원본 데이터에 "신고 건수" 컬럼이 없어서, 발생자 수 × 발견율로 "환산 신고 건수"를 먼저 만들어 가중평균해야 합니다:
1. 행 단위 계산된 필드 `환산신고건수` (SUM 없이, 행 레벨 계산):
```
[Incidence_Cases] * [Case_Detection_Rate_pct] / 100
```
2. 그 다음 당해/전년 집계:
```
발견율_당해연도 = SUM(IF [Year]=[기준연도] THEN [환산신고건수] END) 
                   / SUM(IF [Year]=[기준연도] THEN [Incidence_Cases] END) * 100
```

**증감 색상/화살표 계산 필드** (지표별로 반복, 예시는 인구 제외 "증가=나쁨" 지표 기준):
```
증감_기호 = IF [OO_증감률] > 0 THEN "▲" ELSEIF [OO_증감률] < 0 THEN "▼" ELSE "―" END
증감_개선여부 = [OO_증감률] <= 0   // 사례발견율만 >= 0 으로 반대로 작성
```

**화면 구성**: 8개 지표마다 워크시트를 하나씩 만들어(`스냅샷_01_인구` ~ `스냅샷_08_발견율`) 각각 "당해연도 값" 텍스트를 크게, 그 아래 "▲/▼ 증감률" 을 작게, `증감_개선여부`에 따라 초록/빨강으로 색을 입혀 배치합니다(마크 카드에서 텍스트 마크 유형 사용, 텍스트 상자 안에 두 줄로 값+증감을 넣고, 증감 부분의 글자색을 `증감_개선여부` 필드로 색상 인코딩). 이 8개 타일을 대시보드에서 격자로 배치하면 스냅샷 패널이 완성됩니다.

> `보기 단위`(전세계/지역/국가) 매개 변수에 따라 스냅샷 값이 자동으로 바뀌게 하려면, 각 워크시트에 **필터**로 아래 계산된 필드를 추가하세요:
> ```
> IF [보기 단위]='전세계' THEN TRUE
> ELSEIF [보기 단위]='지역' THEN [Region_Name]=[지역 선택]
> ELSEIF [보기 단위]='국가' THEN [Country]=[국가 선택]
> END
> ```
> 이 필터를 참(TRUE)만 통과하도록 설정하면, SUM() 계산이 자동으로 해당 스코프 안의 국가들만 더하게 됩니다.

## 7. 국가별/지역별 순위 테이블 (클릭 정렬)

디자인 스펙의 랭킹 테이블입니다. Tableau의 **텍스트 표(크로스탭)** 는 컬럼 머리글을 클릭하면 자동으로 오름차순/내림차순 정렬되는 기능이 기본 내장되어 있어 별도 설정 없이 "클릭 정렬"이 됩니다.

1. 새 워크시트 `03_국가순위`
2. **Country** 를 행(Rows), **`선택지표_비율(10만명당)`** 과 **`선택지표_절대값`** 을 열(Columns)에 순서대로 드래그 → 마크 유형이 자동으로 "텍스트 표"가 됩니다
3. `Region_Name` 도 행(Rows)에 Country 앞에 추가하면 지역별로 그룹핑된 표가 됩니다
4. 완성 후 열 머리글의 작은 정렬 아이콘(▲▼)을 클릭하면 그 열 기준으로 즉시 재정렬됩니다 — 최종 사용자(WHO 직원)도 별도 학습 없이 바로 쓸 수 있는 기본 기능입니다
5. Year는 5단계에서 만든 `기준연도` 매개 변수로 필터링(6단계와 동일한 필터 계산식 재사용)

## 8. 데이터 한계 안내 텍스트 상자

1. 대시보드 화면에서 왼쪽 개체 목록의 **"텍스트"** 개체를 대시보드로 드래그
2. 디자인 스펙 "⑥데이터 한계" 섹션의 4개 항목을 그대로 입력 (예: 추정치 특성 — WHO 모델링 기반 50th percentile 값, 실측 신고자료 아님 / Case detection rate 200% 초과 가능성 등)
3. 기본적으로 접혀 보이지 않게 하려면, 이 텍스트 개체를 담은 **"컨테이너"** 를 대시보드 하단에 배치하고, 별도의 "자세히 보기" 토글 버튼을 두려면 **"표시/숨기기 버튼"**(대시보드 개체 목록의 아이콘) 기능으로 컨테이너를 여닫을 수 있습니다.

## 9. 대시보드로 조합하기

1. 하단 탭에서 **새 대시보드** 클릭, 크기를 "자동" 또는 "고정 크기(예: 1600×2200)" 로 설정
2. 왼쪽 시트 목록에서 순서대로 드래그해 배치:
   - 맨 위: `지표 선택` 매개 변수 컨트롤 (가로로 길게)
   - 그 아래: `01_전세계추이` 워크시트
   - 그 아래: `보기 단위` / `지역 선택` / `국가 선택` 매개 변수 컨트롤들 (한 줄에 나란히)
   - 그 아래: `02_세계지도` (좌) + `기준연도` 매개 변수 슬라이더 (지도 위나 옆에)
   - 그 아래: 8개 `스냅샷_XX` 타일을 격자(가로 4×세로 2 또는 가로 2×세로 4)로 배치
   - 그 아래: `03_국가순위` 표
   - 맨 아래: 8단계 데이터 한계 텍스트
3. 제목 추가: 대시보드 상단에 텍스트 개체로 "전세계 결핵 부담 추이 및 국가별 상황" 삽입

## 10. 게시 및 공유

1. 메뉴 **파일 → Tableau Public에 저장** 클릭 → Tableau Public 계정으로 로그인
2. 통합 문서 이름 입력 후 게시 → 완료되면 자동으로 브라우저에 웹 링크가 열립니다

## 자주 발생하는 문제

| 증상 | 원인 / 해결 |
|---|---|
| 지도에 일부 국가가 안 나타남 | 국가명 자동 매칭 실패 → 지도 경고 아이콘 → "위치 편집"에서 수동 매칭 |
| 이중 축 두 그래프의 막대/선이 겹쳐서 안 보임 | "축 동기화"가 켜져 있는지 확인(꺼야 함), 또는 왼쪽/오른쪽 축 범위를 수동 고정 |
| 색상이 극단값 한두 개 때문에 대부분 국가가 비슷한 색으로 보임 | 4-1단계의 "고급 → 시작/끝 값" 캡 설정을 다시 확인 |
| 스냅샷 지표 값이 0 또는 Null로 나옴 | `기준연도`가 1990이면 "전년도"가 존재하지 않아 증감률 계산 불가 — 정상 현상이며, 1991년 이상부터 정상 표시 |
| 매개 변수를 바꿔도 지도/차트가 안 바뀜 | CASE문의 매개 변수 값 목록 문자열이 정확히 일치하는지 확인(예: 공백이나 괄호까지 정확히 같아야 함) |
